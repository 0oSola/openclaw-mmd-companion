# 02 — 场景文档 v2 与 v1 兼容迁移

**What to build:** 让已有 Reze 场景在首次打开时安全升级为第二版文档，保留场景、调色、背景和旧单材质选择，并为样式组基线、单材质图覆盖和人工分组覆盖建立独立持久化字段。

**Blocked by:** 01 — 隔离 Reze 编辑器领域状态与引擎适配接缝.

**Status:** ready-for-agent

- [ ] v2 文档包含规范中的 `groupGraphBindings`、`materialGraphOverrides`和`materialGroupOverrides`，并继续保存现有场景字段。
- [ ] v2 存在时优先读取 v2；只有 v2 不存在时才读取同一用户、模型和管线的 v1。
- [ ] v1 `materialPresets`逐项迁移为单材质图覆盖，旧`默认`保持显式默认图语义。
- [ ] 旧`半透材质`迁移为`柔滑布料`，不迁移为丝袜；新导出不产生旧值。
- [ ] 迁移成功后保留原 v1 键，并向用户反馈迁移条目数和旧值替换数。
- [ ] 无效旧条目产生警告但不阻止其他有效条目迁移。
- [ ] v1 解析失败、v2 规范化失败或存储写入失败时不覆盖旧值、不写空 v2，并显示明确错误。
- [ ] `reze-design`与`reze-k3`继续按用户、模型和管线隔离，互不读取对方文档。
- [ ] 最终图解析顺序和重置矩阵具有纯数据测试。
- [ ] JSON 场景导入和导出使用 v2 契约，并拒绝未知版本。
