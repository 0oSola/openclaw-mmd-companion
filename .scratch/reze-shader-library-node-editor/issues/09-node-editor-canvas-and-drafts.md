# 09 — 40 节点驱动的编辑画布与草稿生命周期

**What to build:** 让用户从空模板、内置图或本地图创建独立草稿，在可视化画布上使用当前引擎注册表全部节点完成添加、删除、移动、连线、断线、属性修改、暴露参数编辑、撤销重做和草稿保存，而不改变当前场景绑定。

**Blocked by:** 06 — 本地图资产导入、应用、导出与收藏纵向链路; 08 — 三栏着色器图库、拓扑预览与响应式目标锁定.

**Status:** ready-for-agent

- [ ] 节点目录由当前引擎注册表驱动，基线 40 种节点类型全部可添加和显示。
- [ ] 宿主为每个节点类型提供中文名称、分类、输入控件和说明；引擎新增节点而元数据缺失时覆盖测试失败。
- [ ] 支持添加、删除、移动、连接和断开节点，并保留`ui.position`往返序列化。
- [ ] 支持编辑节点字面量输入和暴露参数，不允许编辑引擎未声明的插槽。
- [ ] 支持缩放、平移和适应画布，初次打开已有图时节点与链接可读。
- [ ] 支持撤销和重做节点、链接、值、参数和位置修改。
- [ ] 空模板新建草稿，内置图通过“复制并编辑”创建草稿。
- [ ] 编辑已可应用本地图时创建新的独立草稿，不原地修改旧资产。
- [ ] 继续已有草稿时复用原草稿 ID，不重复复制。
- [ ] 草稿自动保存到当前用户仓储，关闭后可以从图库继续编辑。
- [ ] 编辑画布阶段不正式应用到舞台，不更新组或材质绑定。
- [ ] 不复制或改写 AGPL 参考编辑器组件源码，并在代码评审中提供独立实现说明。
