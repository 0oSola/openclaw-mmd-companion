# 05 — 材质跨组移动与自动分类修正

**What to build:** 让用户通过拖放或“移动到样式组…”菜单把 PMX 材质移到任意标准类别或未分组，并可恢复自动分类；移动后单材质图覆盖保持不变，没有覆盖时跟随新组基线。

**Blocked by:** 04 — 九类样式组、组基线与单材质快速选择.

**Status:** ready-for-agent

- [ ] 自动分类覆盖九类与未分组，并与材质树、最终绑定解析共用同一纯函数。
- [ ] 丝袜提示优先于 body/skin，金属、粗糙布料和柔滑布料拥有独立规则和测试。
- [ ] 无法匹配的材质进入未分组，不用默认材质类别掩盖未知语义。
- [ ] 材质叶支持拖放到另一组，成功后写入人工分组覆盖。
- [ ] “移动到样式组…”菜单始终列出九类和未分组，包括当前为空的组。
- [ ] 菜单路径可仅用键盘和辅助技术完成，不依赖拖放。
- [ ] “恢复自动分组”只删除人工分组覆盖，不删除单材质图覆盖。
- [ ] 移动后已有单材质图覆盖继续生效；无覆盖材质改为跟随新组基线。
- [ ] 模型重载和管线重开后人工分组仍从 v2 文档恢复。
- [ ] 矮窗口中的拖放目标、菜单和恢复操作可滚动到达，不与材质检查器重叠。
