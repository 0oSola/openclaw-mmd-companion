# 04 — 九类样式组、组基线与单材质快速选择

**What to build:** 让用户在完整九类与未分组材质树中，通过组标题快速选择器修改组基线，并通过单材质检查器选择任意图或跟随样式组，同时获得清晰的覆盖数量、编译状态和重置语义。

**Blocked by:** 03 — WebGPU 着色器异步应用事务.

**Status:** ready-for-agent

- [ ] 材质类别完整包含默认材质、角色皮肤、眼睛、面部、头发、金属、粗糙布料、柔滑布料、丝袜和未分组。
- [ ] 类别与图名称按`中文（English）`显示，材质树默认只展示非空组。
- [ ] 九个内置图全部来自引擎公开预设，旧`半透材质`不再出现在新选择菜单。
- [ ] 每个非空组标题提供保持打开的快速选择器，显示已提交勾选和独立编译中状态。
- [ ] 组快速选择通过样式组基线提交，不批量写入单材质图覆盖。
- [ ] 单材质检查器第一项是“跟随样式组：中文（English）”，选择后删除该材质覆盖。
- [ ] 单材质可以选择任意内置图形成覆盖，组标题显示准确覆盖数量。
- [ ] 切换组基线时已有单材质图覆盖保持不变。
- [ ] “恢复推荐图”“重置此材质”“恢复全部默认”符合数据契约的重置矩阵。
- [ ] 恢复全部默认不改变灯光、相机、背景、调色、模型或人工分组。
- [ ] `reze-design`与`reze-k3`各有一条快速选择成功的端到端测试。
