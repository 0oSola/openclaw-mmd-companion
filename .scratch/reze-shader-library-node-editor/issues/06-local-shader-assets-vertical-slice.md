# 06 — 本地图资产导入、应用、导出与收藏纵向链路

**What to build:** 让当前用户可以导入一个本地着色器图、在现有材质入口看到它、应用到当前材质、跨模型再次使用、导出标准 JSON，并收藏内置或本地图，形成用户级资产的第一条完整纵向链路。

**Blocked by:** 02 — 场景文档 v2 与 v1 兼容迁移; 03 — WebGPU 着色器异步应用事务.

**Status:** ready-for-agent

- [ ] 建立按当前 `userId`隔离的 IndexedDB 图资产和收藏仓储。
- [ ] 内置图仍由只读清单提供，不复制进 IndexedDB。
- [ ] 支持导入标准资产包和纯`ShaderGraph` JSON；导入始终生成新的本地图 ID。
- [ ] 纯图导入默认使用`renderClass=auto`和`alphaMode=opaque`，并向用户显示可调整提示。
- [ ] 图结构错误、未知节点、超限节点或未知契约版本不会写入 IndexedDB。
- [ ] 导入结果先成为草稿；通过真实异步应用事务成功后才转为可应用资产。
- [ ] 当前材质可以选择本地图并把稳定图引用写入 v2 文档，场景不复制图 JSON。
- [ ] 切换到另一模型后，同一用户仍可看到并应用该本地图。
- [ ] 切换用户后不能读取、搜索或直接按 ID 打开其他用户资产。
- [ ] 内置图和本地图使用同一收藏记录机制。
- [ ] 标准导出包不包含用户 ID、本地资产 ID、收藏状态、场景引用或仓储键。
- [ ] IndexedDB 不可用时内置图仍可使用，本地图功能显示明确不可用状态且不降级到全局 localStorage。
