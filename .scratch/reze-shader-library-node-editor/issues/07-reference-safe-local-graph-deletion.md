# 07 — 被引用本地图的替代删除

**What to build:** 让用户删除本地图时，系统先列出当前用户所有模型和两条 WebGPU 管线中的组或材质引用；存在引用时必须选择可应用替代图，全部场景改写成功后才删除资产。

**Blocked by:** 06 — 本地图资产导入、应用、导出与收藏纵向链路.

**Status:** ready-for-agent

- [ ] 无引用本地图可以删除，并同时清理当前用户收藏记录。
- [ ] 引用扫描覆盖当前用户全部 v2 场景文档、当前正式提交事务和打开的编辑器恢复点。
- [ ] 引用列表显示管线、模型和组或材质目标，不暴露无意义的内部引擎组 ID。
- [ ] 存在引用时直接删除被阻止，用户必须选择一个`ready`替代图。
- [ ] 替代图不能是待删除图，且必须能解析为当前用户可访问的内置或本地图。
- [ ] 全部可解析场景先替换图引用，全部写入成功后才删除原资产。
- [ ] 任一场景损坏、无法解析或写入失败时，整个删除操作失败并保留原资产和原引用。
- [ ] 替换操作不改变样式组类别、人工分组、灯光、相机或背景。
- [ ] 多模型、双管线、组基线和单材质覆盖引用均有自动化测试。
- [ ] 删除和替代结果提供明确成功或失败摘要。
