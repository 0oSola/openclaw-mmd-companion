# 08 — 三栏着色器图库、拓扑预览与响应式目标锁定

**What to build:** 让用户从样式组、单材质或材质页顶部打开完整着色器图库，在明确锁定的目标下筛选内置和本地图、查看统一拓扑预览与详情，并在桌面三栏或窄屏两级页面中安全应用。

**Blocked by:** 04 — 九类样式组、组基线与单材质快速选择; 06 — 本地图资产导入、应用、导出与收藏纵向链路; 07 — 被引用本地图的替代删除.

**Status:** ready-for-agent

- [ ] 图库作为舞台上方独立大弹层打开，不塞进窄 Reze 编辑器 Dock。
- [ ] 桌面布局包含筛选栏、图卡片网格和详情栏；窄屏降级为列表与详情两级页面。
- [ ] 支持内置或本地、推荐类别、标签、收藏和文本搜索筛选。
- [ ] 从组快速选择器打开时目标锁定为该组；从单材质检查器打开时锁定为该材质。
- [ ] 从材质页顶部打开时默认当前材质，并提供显式切换到所属组的控件。
- [ ] 浏览卡片、筛选和查看详情不会悄悄改变应用目标。
- [ ] 应用按钮明确写出目标名称和“样式组”或“材质”类型。
- [ ] 模型、管线或目标材质变化使目标失效时，图库关闭或禁用应用并说明原因。
- [ ] 内置图和本地图使用同一确定性拓扑 SVG 生成逻辑；存在节点位置时优先使用，没有时生成布局。
- [ ] 详情显示放大拓扑、节点数量、双语名称、标签、说明、推荐类别、`renderClass`和`alphaMode`。
- [ ] 图库不把拓扑 SVG 描述为真实材质效果；背后的 MMD 舞台承担实时视觉预览。
- [ ] 高度不高于 560px 时，图库列表、详情和材质树分别可滚动，所有主要操作可达且无重叠。
