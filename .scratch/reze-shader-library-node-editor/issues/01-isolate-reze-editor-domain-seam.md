# 01 — 隔离 Reze 编辑器领域状态与引擎适配接缝

**What to build:** 在不改变现有用户行为的前提下，把 Reze 编辑器的场景文档、材质分组、图绑定计算、运行时调用和持久化编排收束到清晰的领域模块与舞台适配接口，使后续迁移、异步提交、图库和节点编辑器可以复用同一条业务接缝。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 当前“场景 / 材质 / 资产 / 渲染”四页的可见行为、默认值、模型切换和 PNG 导出不变。
- [ ] `reze-design`、`reze-k3`与现有 Three.js Reze 调试路径的启用条件不被扩大或缩小。
- [ ] 场景文档读写、材质视图派生和舞台命令不再散落在页面事件处理器中，后续功能有一个明确的领域入口。
- [ ] 舞台适配器可以用可控制的测试替身返回成功、失败和异步结果，测试不依赖 React 内部 state。
- [ ] 现有 Reze 材质库和舞台调试端到端测试保持通过。
- [ ] 生产构建通过，且没有改变现有 localStorage 键和值。
- [ ] 本票只做行为保持的前置整理，不引入 v2 字段、新图库或节点编辑器 UI。
