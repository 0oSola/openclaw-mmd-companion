# 03 — WebGPU 着色器异步应用事务

**What to build:** 让用户对当前材质选择一个内置着色器图时，舞台等待完整图校验、WGSL 和 WebGPU 管线创建结果；只有最新请求成功并完成场景写入后才提交勾选和正式绑定，失败时自动保留或恢复旧图。

**Blocked by:** 02 — 场景文档 v2 与 v1 兼容迁移.

**Status:** ready-for-agent

- [ ] 舞台提供可等待的着色器应用接口，返回成功、失败、被更新请求取代和目标丢失结果。
- [ ] 旧同步 `setMaterialPreset()`不再承担 WebGPU 新工作流的成功承诺。
- [ ] 点击图后显示编译中，编译期间旧图继续渲染，已提交勾选不提前改变。
- [ ] 图结构、WGSL、管线和目标诊断按阶段返回；存在节点 ID 时可供 UI 定位。
- [ ] 引擎成功且场景文档写入成功后，舞台、界面和 v2 绑定使用同一个结果提交。
- [ ] 场景文档写入失败时恢复事务开始前的正式图，不留下只在当前画面生效的半提交状态。
- [ ] 同一材质快速连续选择时，只有最后一次仍为最新世代的成功结果可以提交。
- [ ] 模型或管线切换导致目标失效时，旧请求不能更新新场景。
- [ ] 成功反馈包含图名、材质名和“单材质”目标语义；失败反馈保留可复制诊断。
- [ ] 使用可控制引擎替身覆盖所有结果，并至少在真实 WebGPU 开发样例上验证一次成功和一次失败回退。
