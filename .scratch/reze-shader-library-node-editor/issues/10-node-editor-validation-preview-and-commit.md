# 10 — 节点诊断、实时预览与正式应用

**What to build:** 让节点编辑器在用户修改草稿后自动校验并异步预览，准确标记问题节点；预览失败时保留上一个成功画面，关闭未应用时恢复进入前的正式图，用户点击“应用”或“应用并关闭”后才提交资产和场景绑定。

**Blocked by:** 03 — WebGPU 着色器异步应用事务; 09 — 40 节点驱动的编辑画布与草稿生命周期.

**Status:** ready-for-agent

- [ ] 编辑后 300ms 无新操作才运行图校验，中间连续修改不会产生多余 GPU 编译。
- [ ] 先运行引擎公共图校验和 WGSL 生成，只有无错误时才发起异步 WebGPU 预览。
- [ ] 诊断按图结构、WGSL、管线和目标阶段展示；有节点 ID 时画布定位并标记对应节点。
- [ ] 实时预览默认开启，并提供明确关闭开关。
- [ ] 预览编译期间保留上一个成功画面；失败时不清空材质、不更新正式绑定。
- [ ] 同一编辑目标的过期预览结果被世代号淘汰，只显示最后一次请求结果。
- [ ] 关闭未应用编辑器后，舞台恢复进入编辑器前的正式图，草稿仍保留。
- [ ] “应用”成功后草稿转为`ready`，目标绑定和 v2 场景文档原子提交，编辑器保持打开。
- [ ] “应用并关闭”使用同一提交事务，成功后关闭；失败时保持打开并显示诊断。
- [ ] 场景写入失败时恢复进入事务前的正式图，草稿保持`draft`。
- [ ] 内置图始终只读，任何正式应用的编辑结果都引用新的本地图 ID。
- [ ] 端到端测试覆盖非法链接、非法参数、WGSL 失败、快速编辑、关闭恢复和成功应用。
