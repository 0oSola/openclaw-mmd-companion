# 05 — Active Agents 统一界面

**What to build:** Pet 提供按活动状态、工作区和来源组织的统一 Agent 会话视图，并支持本地会话聚焦/恢复。

**Blocked by:** 04 — 运行时增强与活跃状态生命周期

**Status:** ready-for-agent

- [ ] 活动会话优先展示，并显示来源、运行方式、工作区、状态、最近活动和 bounded 输出。
- [ ] 同时存在多个工作区时按工作区分组，不再只显示当前选中工作区。
- [ ] 本地活动会话可以聚焦已有窗口或进入恢复路径。
- [ ] 远程或无法聚焦的会话显示明确的能力边界，不伪造已打开。
- [ ] 既有 More Sessions 搜索、脱敏和菜单即时响应行为保持通过。
