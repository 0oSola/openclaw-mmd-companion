## 一、坐标系定义

### 1.1 PMX 模型空间

| 轴 | 正方向 | 说明 |
|---|---|---|
| X | 模型左侧 | 右手系，右臂在 -X 侧 |
| Y | 上方 | 骨骼原点在脚底，头顶 Y≈21.65 |
| Z | 后方 | 负 Z = 前方（脸朝 -Z 方向） |

### 1.2 渲染世界空间

PMX → 渲染坐标变换公式:

```
render_x = PMX_SCALE * pmx_x + offset_x
render_y = PMX_SCALE * pmx_y + offset_y
render_z = -PMX_SCALE * pmx_z + offset_z   (Z 轴翻转)
```

参数:
- PMX_SCALE = 0.9
- PMX_OFFSET = (0.0, -9.738, 0.697)

### 1.3 BVH → PMX 映射

- BVH: Y-up, Z-forward (右手系)
- PMX: Y-up, Z-back (左手系)
- 位置映射: `pmx = pmx_pelvis + (bvh - bvh_pelvis) * 8.54 * [1, 1, -1]`
- 旋转映射: Z 轴取反 (`pmx_dir = [bvh_x, bvh_y, -bvh_z]`)

### 1.4 前方轴方向

PMX 模型「前方」并非纯 Z 轴，前方轴 = `(0, 0.14, 0.99)`，Y 轴有 14° 倾斜。计算前深度时必须沿此前方轴投影。

| 膝关节 | 15° | 175° | 防止反弯 |

### 6.2 最大角速度 (Stage 4)

| 部位 | max_angular_velocity | 说明 |
|---|---|---|
| 躯干 | 0.15 rad/frame | 最严格 |
| 上臂 | 0.25 rad/frame | |
| 前臂 | 0.35 rad/frame | |
| 手指 | 0.40 rad/frame | 最宽松 |

加速度限制: max_acceleration_ratio = 2.0

### 6.3 优先级约束 (Stage 5)

按优先级从高到低:
1. 碰撞约束 (前深度 + 躯干间隙)
2. 关节角度限制
3. 目标位置 (FABRIK IK 到下巴)
4. 路径约束 (手腕保持在前方)
5. 运动平滑

### 6.4 躯干前倾补偿 (Stage 6)

当手腕目标超出臂展时，迭代前倾上半身 (最大 10°, 步进 0.5°)。
