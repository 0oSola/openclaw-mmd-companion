【全体の注意事項】
　待機モーションからの遷移は事実上行っていないようなもののため、動作のウェイトは標準の2倍～3倍推奨です。モーション全般、使用用途に応じて適宜調整を入れることを想定しています。
　
　RecotteStudioで出力した動画内でモーション中にモデルの物理演算が働いていない場合は、
　1.MMDから、下の方にある モデル操作＞読込　で使用するモデルを読み込む
　2.上のツールバーからファイル＞モーションデータ読み込み　で使いたいモーションを読み込む
　3.モーションを保存する
　4.RecotteStudioからモーションを一回削除してもう一度登録する
　これでいけると思います。

【モーション紹介】

000_ベース_作業用
000_ベース2_作業用
　モーション作成時のベースとして使用します。各自使用している待機モーションまたはそれに似たポーズに置き換えると使いやすいと思います。

000_表情モーション_作業用
　モデルの表情だけ変えたいときに使用します。現在は適当にRecotte Studio標準の待機モーションっぽい感じのポーズにしています。MMDから000_表情モーション_作業用を開き、モーフで表情を変えて表情用モーションとして保存します。
各自使用している待機モーションまたはそれに似たポーズに置き換えると使いやすいと思います。

【ループ用】
動作の設定から「繰り返し」にチェックを入れて使用する想定のモーションです。

煽り_L
　「小学生までだよねー」とか言いたい時に使うことが出来ます。呼吸程度の動きに抑えたループ用

訝しんだ_L
　訝しみたい時に使うことが出来ます。呼吸程度の動きに抑えたループ用

エアろくろ_L
　何かを力説したい時に使うことが出来ます。表情を変えた方がいいかも
